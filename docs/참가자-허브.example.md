# 참가자 허브 안내 — 공개용 예제

이 문서는 자리표시자만 포함합니다. 기존 참가 안내 원문은 로컬에 보존하고
Git에서 제외합니다. 원문의 비밀번호·팀 접근 코드·이메일을 복사하지 마세요.

- 허브 주소: `<HUB_URL>`
- 허브 비밀번호: `<HUB_PASSWORD>`
- 팀 접근 코드: `<TEAM_ACCESS_CODE>`
- 확인용 이메일: `<TEAM_EMAIL>`

실제 접근정보는 팀의 비공개 전달 경로에서 확인하세요. 앱 API 키는 별도이며,
`main/handoff-package/.env.example`에 설명된 로컬 환경변수로 설정합니다.
