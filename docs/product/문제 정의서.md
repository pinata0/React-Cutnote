고객(사용자)은 누구인가요?
영상 편집자, 모션그래픽 디자이너, 콘텐츠 크리에이터, 광고·브랜드 디자이너처럼 이미지와 영상을 참고해 새로운 결과물을 만드는 시각 콘텐츠 제작자입니다. 개인 제작자뿐 아니라 여러 사람이 레퍼런스를 공유하고 제작 방향을 맞춰야 하는 콘텐츠 제작팀도 포함됩니다.

고객은 어떤 문제를 겪고 있나요?
시각 콘텐츠 제작자는 여러 플랫폼에서 발견한 이미지와 영상을 캡처, 링크, 다운로드 파일 등 서로 다른 형태로 저장합니다. 하지만 자료가 폴더, 메모 앱, SNS 저장 목록 등에 흩어지고, 파일명이나 출처만으로는 색감·구도·움직임·효과·분위기를 검색하기 어렵습니다.

그 결과 원하는 레퍼런스를 찾기 위해 많은 자료를 반복해서 확인해야 하며, 비슷한 효과를 비교하거나 어떤 제작 방식을 참고할지 판단하기도 어렵습니다. 팀 작업에서는 같은 효과를 서로 다른 용어로 표현해 의도를 정확히 공유하기 어렵고, 이미 수집한 자료가 개인의 기억에만 의존하는 문제도 발생합니다. 결국 레퍼런스가 충분히 쌓여 있어도 실제 기획과 제작 과정에서 제대로 활용되지 못합니다.
