# 컷노트(Cutnote) 서비스 소개

> **저장한 영감이 다음 작품으로 이어지는 곳, 컷노트.**

기준일: 2026-10-03 · 현재 소스와 기술문서 기준. 구현 여부와 실제 환경의 품질 검증은 구분합니다.

컷노트는 **영상 편집자가 원하는 효과의 레퍼런스를 찾고, 필요한 장면을 기록해 다음 작업에 활용할 수 있도록 돕는 서비스**입니다. 편집자가 다양한 특수효과의 활용 사례를 살펴보고 자신의 영상에 더 잘 적용할 수 있도록 돕고자 합니다.

프로젝트는 원하는 효과가 잘 사용된 영상을 찾는 구글링에 너무 많은 시간이 든다는 경험에서 출발했습니다. 찾은 장면은 Notion이나 Obsidian에 링크와 스크린샷으로 남겼지만, 자료가 쌓이면 어떤 영상의 어느 부분을 참고하려 했는지 다시 찾아야 했습니다. 컷노트는 레퍼런스 탐색과 장면별 기록을 연결해 이 수고를 줄이고자 합니다.

## 사용 흐름

1. **수집** — YouTube·Instagram 링크나 직접 가진 영상 파일을 등록하고 참고 이유를 남깁니다.
2. **분석·기록** — 분석 가능한 영상에서 AI가 색감·구도·효과와 참고 구간을 제안합니다. 사용자는 근거 시점을 확인하고, 구간별 태그·시간·메모를 수정하거나 제안을 승인·거절할 수 있습니다.
3. **검색·활용** — 제목·메모·태그와 복합 조건으로 필요한 장면을 찾고 재생합니다. 사진을 넣어 색감·구도·질감 등 정적인 특징이 비슷한 보관함 구간을 찾을 수도 있습니다.
4. **효과 탐색** — 원하는 연출을 입력하거나 저장된 구간을 선택하면, 보관함에서 조건에 맞는 장면과 유사한 효과의 장면을 구분해 보여줍니다. 유사한 이유를 확인하고 선택형 피드백을 남길 수 있습니다.
5. **새 레퍼런스 발견** — 저장한 자료의 확정 태그와 즐겨찾기를 참고해 YouTube 영상·쇼츠 후보를 찾습니다. 비슷한 스타일과 새로운 스타일을 나눠 살펴보고 보관함에 추가할 수 있습니다. 이 후보는 공개 검색 정보 기반이며 영상 속 효과를 분석해 확인한 결과는 아닙니다.

예를 들어 영상의 12~15초 화면 전환에 효과 태그와 “다음 홍보 영상 도입부에 참고”라는 메모를 남길 수 있습니다. 이후에는 제목을 기억하지 않아도 해당 효과나 메모로 장면을 다시 찾아볼 수 있습니다.

## 기술적 특징

외부 AI의 영상 분석에 **컷노트가 설계한 편집 효과 분류 체계와 유사 효과 탐색 알고리즘**을 결합했습니다. 현재 사전은 12개 분류 영역, 403개 태그로 구성되며, 분석 결과를 장면과 근거 시점에 연결합니다. 관찰 가능한 특징과 추정에 불과한 제작 기법을 구분하고, 사용자가 내린 승인·거절은 재분석에서도 보존합니다.

효과 탐색은 구간의 확정 태그와 태그 간 관계를 비교합니다. 정확히 조건을 충족하는 결과를 우선하고, 효과 종류·움직임·질감과 형태·분위기 순으로 비교해 유사한 이유를 설명합니다. 피드백은 같은 검색 조건의 결과 순서와 노출에 반영합니다. 자체 AI 모델 학습이나 파인튜닝을 구현했다는 의미는 아닙니다.

## 현재 구현 단계

핵심 기능을 구현한 프로토타입입니다. 영상 수집, AI 분석·검수, 구간별 기록·재생, 텍스트·태그·사진 검색, 효과 탐색·피드백, 영상·구간 즐겨찾기, YouTube·쇼츠 추천을 구현했습니다.

Android 공유와 PC 보관함 연결, 같은 LAN의 다른 PC 브라우저 접근도 구현했습니다. PC와 연결 서버가 실행 중이어야 하며, 온라인 배포 보관함과 PC 로컬 보관함은 별도입니다.

최신 검증에서 Instagram 테스트 영상 한 개의 실제 다운로드·프레임 추출과 PC 브라우저 원본/구간 재생·탐색을 확인했습니다. YouTube 테스트 다운로드는 429/로그인 요구로 실패했습니다. 실제 OpenAI 분석 완료·구간 재분석과 최신 Android 기기의 공유→접수→화면 종료→완료는 미검증입니다. 자동 테스트 통과를 실제 서비스 전체 성공이나 분석 품질 검증으로 보지 않습니다.

앞으로 실제 편집 작업에서 탐색 시간과 재사용 경험, 분석·추천 품질을 검증하고자 합니다. 컷노트의 목표는 편집자가 자료를 찾고 정리하는 시간을 줄이고, 좋은 효과를 자신의 영상에 어떻게 활용할지 고민하는 데 더 많은 시간을 쓰게 하는 것입니다.

## PC 링크 등록과 휴대폰 공유

1. [설치 안내](../engineering/setup.md)에 따라 PC를 준비합니다. Windows에서 검증한 Node 실행기, yt-dlp·FFmpeg·ffprobe, 인터넷 연결과 OpenAI API 키가 필요합니다. PC에서 저장 폴더와 도구 경로를 지정하고 OpenAI를 연결합니다.
2. PC에서는 영상 링크를 입력하고 **PC에 저장하고 분석**을 누릅니다. 공개된 개별 YouTube·Instagram 영상 주소를 대상으로 하며, 다운로드 권한이 있는 자료를 사용합니다.
3. 휴대폰에서는 같은 신뢰할 수 있는 Wi-Fi에 연결하고 설치된 Android 앱에 PC 실행기가 안내하는 주소·연결 코드를 입력합니다. YouTube 앱의 공유에서 컷노트를 선택합니다. 코드와 주소는 공개 문서나 채팅으로 공유하지 않습니다.
4. **PC 접수 완료**를 확인한 뒤에는 모바일 화면을 닫아도 PC 작업자가 처리하도록 구현했습니다. 다시 접속하면 작업 목록에서 단계·실패·결과를 확인합니다. PC 실행기는 켜두어야 하며 절전·전원 종료 상태에서는 처리하지 않습니다.
5. 다운로드한 원본을 재생하고, 분석 결과를 확인해 태그·구간·메모를 수정합니다. 분석만 실패했다면 원본을 보존한 채 재시도할 수 있습니다. 같은 보류 공유의 재전송은 중복을 막지만 새로 공유하면 별도 항목이 생깁니다.

Android 8.0 이상과 최신 WebView가 필요하며, 현재 소스의 APK 빌드·실기기 검증은 남아 있습니다. 설치와 접속, 오류별 대응은 [PC 운영 안내](../engineering/local-video-ingestion-operations.md)와 [Android 안내](../engineering/android.md)를 따릅니다.

## 저장 위치와 외부 AI 사용

PC 링크 수집의 영상·썸네일·구간 파일은 지정한 PC 폴더에 저장됩니다. 제목·태그·메모·분석 결과·작업 상태는 PC 보관함 DB에 저장됩니다. 기존 파일 업로드는 별도 객체 저장소(R2, PC 실행에서는 로컬 에뮬레이션)를 사용합니다. 온라인 사이트의 보관함으로 자동 복사되지는 않습니다. 보관함 항목을 삭제해도 PC 수집 파일은 자동으로 영구 삭제하지 않습니다.

**로컬 저장은 완전한 오프라인 분석이 아닙니다.** 새 경로는 원본에서 뽑은 최대 120개의 이미지, 시점·영상 길이와 분석 지시·태그 체계를 OpenAI로 보내 분석합니다. 이 경로에서 원본 전체 파일이나 음성을 분석 입력으로 보내지는 않습니다. OpenAI API 키·모델 접근·사용 비용과 인터넷 연결이 필요합니다. 사진 검색은 입력 사진, 자연어 효과 검색은 검색 문구를 선택한 외부 AI 제공자에게 보냅니다.

새 PC 링크 수집·로컬 원본 재분석은 Google Data API와 Gemini에 의존하지 않습니다. 플랫폼 웹페이지/CDN에서는 영상을 내려받으며 Google의 동의 페이지를 거칠 수 있습니다. 기존 직접 영상 분석과 사진·효과 검색에는 Gemini 선택지가 남아 있습니다. 모든 외부 API를 없앤 제품으로 설명하지 않습니다.

## 지원 범위와 제한

원본은 최대 2GiB·2시간이며 시작 전 5GiB 여유 공간을 확인합니다. PC는 한 번에 한 작업을 처리합니다. 로컬 구간 파일은 5분·25MiB·최대 360p이고 Android 기기에 파일을 저장하는 기능도 25MiB 제한이 있습니다. 큰 원본의 PC 보관과 스트리밍 재생은 이 제한과 별개입니다.

로그인 필수 영상·플랫폼 차단·삭제·속도 제한으로 다운로드가 실패할 수 있습니다. 쿠키 자동 가져오기, 라이브·재생목록·Instagram 여러 항목 전체 수집, 인터넷을 통한 원격 접속·계정 동기화는 지원하지 않습니다. 실패 시 상태와 재시도를 확인하거나 권한 있는 원본 파일을 첨부합니다. 샘플 분석은 짧은 효과를 놓칠 수 있으므로 결과는 사용자가 검토해야 합니다.
