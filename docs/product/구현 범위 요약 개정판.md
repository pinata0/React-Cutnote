# 구현 범위 요약

기준일: 2026-10-03 · 현재 소스와 기술문서 대조. 과거 MVP 계획을 현재 구현 상태로 갱신했습니다. 이번 문서 갱신에서 앱·외부 API·실기기를 새로 실행하지 않았습니다.

## 문제와 목표

영상 편집자가 원하는 효과의 레퍼런스를 찾는 구글링에 많은 시간을 쓰고, 발견한 장면을 Notion·Obsidian에 링크·스크린샷으로 기록해도 다음 작업에서 다시 찾기 어렵다는 경험에서 출발했습니다. 컷노트는 **레퍼런스 수집 → 분석·장면별 기록 → 검색·활용 → 새로운 후보 발견**을 연결합니다.

## 현재 구현한 기능

| 영역 | 구현 내용 | 조건·범위 |
|---|---|---|
| 수집 | YouTube·Instagram 링크, 영상 파일, 제목·메모 저장 | 원본 접근·분석 가능 여부는 플랫폼과 제공자에 따라 다름 |
| AI 분석 | OpenAI 프레임 입력, Gemini 영상 입력으로 특징·구간·근거 시점 제안 | 최대 2시간·30구간. OpenAI 최대 120프레임, Gemini 2fps 설정. 빠른 효과 누락 가능 |
| 분류·검수 | 12개 영역·403개 태그, 별칭·계층 관계, 승인·거절·수정, 재분석 시 사용자 판단 보존 | AI 점수는 실측 정확도 확률이 아님. 제작 방식 추정은 자동 확정하지 않음 |
| 장면 기록 | 시작·끝·제목·메모·구간별 태그, 구간 재분석 | 구간 기록과 실제 구간 영상 파일은 별개 |
| 검색 | 텍스트·태그·복합 필터, 사진의 정적 특징과 구간 태그 비교 | 사진 한 장으로 시간적 움직임을 확인하지 않음 |
| 효과 탐색 | 자연어·선택 구간 기반 검색, 조건 일치·유사 효과 구분, 유사 이유 표시 | 저장된 구간의 확정 태그와 명시적 유사 효과 규칙 사용 |
| 피드백 | 원하는 효과 / 비슷하지만 다름 / 관련 없음 선택·변경·취소 | 같은 검색 조건의 순위·노출에 적용. 모델 재학습 아님 |
| 보관함 | 영상·구간 즐겨찾기, 보관함 순서 저장 | 저장소별로 관리 |
| 새 영상 추천 | 확정 태그·즐겨찾기 기반 YouTube 영상·쇼츠 후보, 비슷한 스타일·새 스타일 구분, 저장·분석 진입 | 공개 검색 정보 기반. 후보의 실제 효과를 분석해 검증한 결과 아님 |
| 재생·파일 | 원본·구간 재생, 접근 가능한 원본의 구간 파일 생성·보관 | 플랫폼·브라우저 조건 적용. 모든 외부 영상의 다운로드를 지원하는 것은 아님 |
| 기기 연결 | Android 공유 수신, LAN Bridge를 통한 PC 보관함 접근, 같은 LAN의 다른 PC 브라우저 접속 | PC·Bridge 실행 필요. 온라인 보관함과 자동 통합하지 않음 |

## 자체 분류·추천 로직

- 영상 분석 결과를 공통 태그 사전의 ID와 근거 시점으로 구조화하고, 관찰 가능성·점수·정책에 따라 확정 또는 제안합니다.
- 효과 탐색은 모든 조건을 만족하는 결과를 우선합니다. 이후 효과 종류, 움직임, 질감·형태, 분위기 순으로 비교하고 명시적으로 정의한 유사 효과 관계를 사용합니다.
- 사진 검색은 태그의 정확한 일치·동등한 외관·상하위 관계에 각각 다른 가중치를 적용합니다.
- 외부 추천은 원본별 태그 기여도를 정규화하고 즐겨찾기에 가중치를 줍니다. 저장한 YouTube 영상은 제외하고, 익숙한 스타일과 다른 스타일의 검색 후보를 제공합니다.
- 위 로직은 외부 AI를 활용하는 제품 알고리즘입니다. 독자 영상 모델 학습·파인튜닝과 구분합니다.

## 구현과 검증의 구분

최근 [검증 기록](../refactoring-study.md)에 오프라인 웹 테스트 12/12 스위트, lint·타입 검사·빌드, 빈 DB 초기화, PC/Bridge HTTP 연동 통과가 있습니다. 테스트는 메모리 DB와 가짜 제공자를 사용하므로 실제 AI의 분석 정확도나 외부 검색 품질을 입증하지 않습니다.

최신 실제 브라우저의 전체 조작·영상 재생, Android APK·실기기 공유·재생, 실제 OpenAI/Gemini·YouTube 응답 품질, 온라인 배포 상태는 그 검증에서 다시 확인하지 않았습니다. 과거 실행 기록과 현재 전체 흐름의 검증을 구분해야 합니다.

## 후속 검증·확장

실제 편집자의 탐색 시간·재사용률, 효과별 누락·오분류, 외부 추천의 적합성, 모바일 안정성을 검증합니다. 팀 공동 보관함·계정 권한·과금은 향후 검토 범위입니다. 인터넷 전체의 정밀한 영상 효과 검색이나 모든 플랫폼의 다운로드를 완료 기능으로 소개하지 않습니다.
