# 유사 효과 탐색 카드

기준일: 2026-10-03 · 아래 예시는 설계 의도를 설명합니다. 자연어 입력·일치/유사 결과 구분·이유 표시·선택 구간 기반 탐색·피드백은 현재 구현되어 있습니다. 실제 재생 동작과 외부 AI 품질은 시연 환경에서 확인해야 합니다. 구현 범위는 [현재 요약](<구현 범위 요약 개정판.md>)을 따릅니다.

**원하는 효과를 입력하면, 그 효과가 적용된 클립과 분위기·움직임이 비슷한 효과의 클립을 함께 보여주는 ‘유사 효과 탐색 카드’**로 구현되어 있습니다. 여기서는 영상 편집 효과를 찾는 상황을 기준으로 잡았습니다.

사용자는 정확한 효과 이름을 몰라도 “화면이 흔들리면서 확대되는 효과”, “몽환적으로 번지는 느낌”처럼 입력할 수 있어요. 카드는 입력 의도를 해석하고, 실제 클립을 보면서 원하는 효과를 좁혀갈 수 있도록 돕습니다.

**카드 안에서의 사용 흐름**

1. **효과 입력**  
   효과명이나 원하는 느낌을 입력합니다. 입력창에는 `예: 글리치, 천천히 확대, 빛이 번지는 느낌`을 안내합니다.

2. **검색 의도 확인**  
   입력 내용을 `화면 흔들림` `확대` `빠른 움직임` 같은 태그로 보여줍니다. 사용자는 태그를 삭제하거나 수정해 검색 의도를 조정할 수 있습니다.

3. **일치하는 클립과 유사한 클립 탐색**  
   결과를 ‘입력한 효과’와 ‘비슷한 효과’로 구분합니다. 일치하는 결과를 먼저 보여주고, 유사 결과에는 **어떤 점이 비슷한지** 짧게 설명합니다.

4. **미리보기와 선택**  
   클립을 누르면 효과가 드러나는 구간을 반복 재생합니다. `이 효과와 비슷한 클립 더 보기`로 탐색을 이어가거나, 클립을 선택·저장합니다.

예를 들어 **“화면이 흔들리면서 확대되는 효과”**를 입력하면 다음처럼 보여줍니다.

| 구분 | 결과 예시 | 표시할 설명 |
|---|---|---|
| 입력한 효과 | 줌과 흔들림이 함께 적용된 클립 | 확대와 화면 흔들림이 모두 포함돼요 |
| 비슷한 효과 | 빠른 줌인 클립 | 화면이 빠르게 다가오는 움직임이 비슷해요 |
| 비슷한 효과 | 카메라 셰이크 클립 | 화면이 흔들리는 움직임이 비슷해요 |
| 비슷한 효과 | 방사형 블러 클립 | 중심으로 몰입되는 느낌이 비슷해요 |

**각 클립에는 판단에 필요한 정보만 표시합니다.**

- 효과가 잘 보이는 썸네일과 짧은 미리보기
- 효과명 및 핵심 태그
- 유사한 이유 한 줄
- 효과가 등장하는 구간
- 선택 또는 저장 버튼

유사도는 **효과 종류 → 움직임 → 시각적 질감 → 분위기** 순으로 비교합니다. 분위기만 비슷한 결과가 정확히 일치하는 결과보다 먼저 나오지 않도록 하고, 근거가 불명확한 유사도 퍼센트보다는 `움직임이 비슷해요`처럼 이유를 보여줍니다.

정확한 결과가 없으면 **“정확히 일치하는 클립은 없지만, 비슷한 움직임의 클립을 찾았어요”**라고 안내합니다. 입력이 “멋있는 효과”처럼 넓으면 `역동적인` `몽환적인` `강렬한` 등의 선택지를 제공해 범위를 좁힙니다.

현재는 **자연어 입력, 일치·유사 결과 구분, 유사한 이유 표시, 구간 선택, 선택 구간 기반 추가 탐색과 선택형 피드백**을 구현했습니다. 구간 재생은 플레이어·원본 접근 조건에 영향을 받습니다. 핵심 성공 기준은 검색 결과의 개수보다 **사용자가 원하는 효과의 클립을 실제로 선택했는지**입니다.
PC 링크 수집과 외부 AI 사용·저장 위치·현재 검증 제한은 [서비스 소개](<서비스 소개문.md>)를 참고하세요. 효과 검색의 제공자 선택과 PC 원본 수집의 OpenAI 전용 경로는 별개입니다.
