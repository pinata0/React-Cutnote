# 구현 범위 요약

## 문제 정의

**원하는 영상 효과를 만들기 위해서는 먼저 그 효과가 실제 영상에서 어떻게 사용되는지 봐야 한다.**

하나의 레퍼런스만 보는 것보다 여러 영상의 사례를 비교해야  
효과의 색감, 구도, 움직임, 강도, 조합 방식을 이해하고 원하는 결과물을 만들기 쉽다.

하지만 현재는 레퍼런스를 발견하더라도 영상 전체를 다시 찾아보거나,  
어떤 영상의 어느 부분에 원하는 효과가 있었는지 기억에 의존해야 한다.

따라서 이 서비스는 **좋은 영상 레퍼런스를 클립 단위로 수집·분류하고, 원하는 조건으로 다시 검색할 수 있는 개인 영상 효과 라이브러리**를 제공한다.

---

## 핵심 사용자 흐름

### 1. 수집

사용자가 YouTube·Instagram 등에서 질 좋은 레퍼런스를 발견하면  
**영상 파일 또는 링크 형태로 서비스에 입력한다.**

예)

- YouTube 영상 링크
- Instagram Reel 링크
- 로컬 영상 파일
- 직접 촬영하거나 저장한 영상

↓

### 2. 클립화

입력한 영상에서 레퍼런스로 사용할 부분을 잘라  
짧은 **클립(Clip)** 단위로 저장한다.

하나의 영상에서도 서로 다른 효과가 사용된 장면을 각각 별도의 클립으로 관리할 수 있다.

예)

```text
00:14 ~ 00:18 → Glitch Transition
00:32 ~ 00:37 → Blue Cinematic Color
01:05 ~ 01:08 → Camera Shake
```

↓

### 3. 분류 및 태깅

각 클립의 시각적 특징을 분석하여 **태그(Tag)** 를 붙인다.

태그는 여러 속성으로 나누어 관리한다.

예)

```text
색감
blue
red
warm
desaturated

구도
close-up
medium-shot
full-shot
wide-shot

효과
glitch
rgb-split
motion-blur
film-grain

움직임
fast
slow
shake
zoom

스타일
cinematic
retro
vhs
dreamy
```

필요한 경우 AI 분석을 통해 태그 후보를 자동으로 생성하고,  
사용자가 직접 수정하거나 추가할 수 있다.

↓

### 4. 검색

사용자가 원하는 조건을 선택하거나 검색하면  
조건에 해당하는 클립들을 출력한다.

문자열 검색뿐만 아니라 여러 필터를 조합하여 검색할 수 있다.

예)

```text
Glitch
+ Blue
+ Full Shot
+ Fast
```

→ 해당 조건을 만족하는 레퍼런스 클립 출력

검색 결과에서는 영상 전체가 아니라  
**실제로 해당 효과가 등장하는 짧은 장면을 바로 확인**할 수 있다.

---

## 외부 레퍼런스 탐색

사용자가 아직 자신의 라이브러리에 충분한 레퍼런스를 가지고 있지 않을 경우,  
현재 선택한 태그를 바탕으로 외부 플랫폼에서 추가적인 사례를 탐색한다.

예)

```text
RGB Split
+ Red
+ Fast
```

↓

서비스가 해당 조건을 기반으로 검색어를 확장하고  
YouTube 등의 외부 영상에서 관련 레퍼런스 후보를 찾는다.

단순히 제목에 `RGB Split`이라는 단어가 포함된 튜토리얼을 찾는 것이 아니라,

**실제 영상 제작물에서 해당 효과가 사용된 사례를 찾는 것**을 목표로 한다.

발견한 영상은 사용자가 자신의 라이브러리에 추가하여  
기존의 **수집 → 클립화 → 태깅 → 검색** 흐름으로 가져올 수 있다.

---

## 전체 흐름

```text
YouTube / Instagram / Local Video
                │
                ▼
              수집
                │
                ▼
              클립화
                │
                ▼
             AI 분석
                │
                ▼
              태깅
                │
                ▼
        개인 레퍼런스 라이브러리
                │
        ┌───────┴────────┐
        ▼                ▼
      검색          외부 레퍼런스 탐색
        │                │
        └───────┬────────┘
                ▼
          레퍼런스 클립 확인
```

## MVP 구현 범위

행사 당일에는 다음 흐름을 핵심으로 구현한다.

**영상 입력 → 클립 생성 → 태그 저장 → 필터 검색 → 클립 결과 출력**

추가적으로 구현 가능할 경우,

- YouTube 기반 외부 레퍼런스 검색
- AI 기반 자동 태그 추천

을 확장 기능으로 추가한다.

Instagram 전체 영상 검색이나 실제 외부 영상의 정밀한 시각 분석 등  
플랫폼 제약과 구현 비용이 큰 기능은 MVP 이후 확장 범위로 둔다.
