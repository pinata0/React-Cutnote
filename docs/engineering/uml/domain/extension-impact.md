## 후속 작업과 검증

태그 생성 명령은 [package.json](../../../../apps/web/package.json)의 `taxonomy:generate`와 build 시작 시 수행하는 check에서 확인했다. 이번에는 생성기를 실행하거나 생성 JSON·런타임 사전 내용을 읽지 않았다. 생성기 소스에서 YAML과 schema를 입력으로 검증·생성하는 구조를 확인했다.

후속 태그 검증은 [segment-tagging-current](../../../../tests/web/segment-tagging-current.test.ts), [segment-independent](../../../../tests/web/segment-independent.test.ts), [image-search](../../../../tests/web/image-search.test.ts), [recommendation](../../../../tests/web/recommendation.test.ts)를 대상으로 한다. 엔진·미디어 변경은 [full-video](../../../../tests/web/full-video.test.ts), [segment-retag-parser](../../../../tests/web/segment-retag-parser.test.ts), [pc-jobs](../../../../tests/web/pc-jobs.test.ts), [runtime](../../../../tests/pc/runtime.test.mjs), [segment-media](../../../../tests/web/segment-media.test.ts)를 검토한다. favorite/order 변경은 [favorites](../../../../tests/web/favorites.test.ts), [discovery-order](../../../../tests/web/discovery-order.test.ts)가 보조 증거다. 이번에는 테스트 파일의 존재와 대상을 확인했으며 실행 통과로 보고하지 않는다.

학습 포인트: DB가 TEXT를 저장할 수 있다는 것은 도메인 파서·AI schema·UI·codec이 새 유형을 지원한다는 뜻이 아니다. taxonomyVersion·engine·fingerprint 같은 문자열은 읽기 호환 계약이다. 후속 작업은 해당 계약의 생성자와 소비자를 함께 수정해야 한다. 실제 서비스 지원과 기기 재생은 추가 실행 검증 대상이다.
