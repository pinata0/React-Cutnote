# 랄프톤 제품 브리프 — Gistatone

## 고정 문장 묶음

RALPHTHON PRODUCT BRIEF schema 1.0

[1 사용자·상황] 영상 편집자는 특수효과 레퍼런스를 모으고, 나중에 필요한 효과 스타일을 다시 찾으려는 상황에서 로컬 라이브러리를 사용한다.

[2 현재 대안] 지금은 인상 깊은 장면을 캡처해 Obsidian에 정리하며, 자료가 쌓이면 원하는 특수효과 스타일을 필요할 때 검색으로 다시 찾기 어렵다.

[3 문제] 우리가 풀 문제는 영상 편집자가 축적한 레퍼런스가 많아졌을 때, 필요한 특수효과 자료를 빠르게 다시 찾기 어렵다는 것이다.

[4 가치 가설] 우리는 사용자가 직접 엄선한 이미지·영상 라이브러리를 자동 분류·태깅하고 여러 필터로 검색할 수 있게 하면, 원하는 특수효과 레퍼런스를 찾는 시간과 탐색 부담이 줄어들 것이라 본다.

[5 근거·미확인] 문제 존재를 뒷받침하는 근거는 팀장이 영상편집 동아리 활동에서 직접 겪은 경험과 다른 제작자들에게 직접 물어 들은 유사 경험이고, 아직 미확인인 것은 실제 검색 시간 절감 정도, 자동 태깅 정확도, 다른 제작자가 지속적으로 사용할지 여부, 완성된 결과물만으로 제작 방식을 추정하는 추천 방식의 신뢰성이다.

[6 핵심 흐름] 편집자가 캡처 이미지 또는 짧은 영상 1~2개를 로컬 라이브러리에 넣는 것 → 제품이 자료를 분류하고 효과명·색감·효과 유형(트랜지션·생성·변형)·카메라 구도와 각도 등의 태깅 데이터를 저장하는 것 → 같은 편집자가 프로세스 윈도우에서 효과명·색감 등의 필터를 조작해 관련 자료와 추천 효과를 보는 것으로 이어진다.

[7 포함 범위] 행사 당일에는 미리 준비된 라이브러리, 신규 자료 1~2개 추가, 자동 분류·태깅, 효과명·색감 등의 필터 검색, 관련 장면의 사진첩 형태 출력, 샷 크기와 피사체 기준 카메라 방향·상하 촬영각 태깅, 완성된 결과물에서 추정한 제작 방식이 유사한 효과 추천만 포함한다.

[8 제외 범위] 행사 당일에는 외부 플랫폼 직접 연동, 모바일 앱 배포, 협업 기능, 검색 전 선제 스타일 추천, 원본 Adobe 프로젝트 파일이나 실제 편집 히스토리 분석, 전체 로컬 미분류 폴더 자동 정리를 핵심 시연 범위에 포함하지 않는다.

[9 기대 결과] 예시 입력 `pixel glitch`에서는 첫 카드에 Pixel Glitch 자료만, 두 번째 카드에 Pixel Glitch·Mosaic Glitch·Block Glitch처럼 제작 방식이나 활용 목적이 가까운 효과군, 세 번째 카드에 AI가 제안하는 더 넓은 glitch 계열 효과가 보여야 핵심 흐름의 작동을 확인할 수 있다. 효과명 필터를 쓰는 경우 효과명은 정확히 일치하는 자료를 우선 보여주고, 효과명 없이 `red`, `blue` 같은 색감 필터만으로도 검색할 수 있다. 사용자 가치 여부는 실제 사용 관찰로 별도 확인하는 것으로 남긴다. 핵심 흐름에 영향을 주는 예외·제약은 추천 제작 방식이 원본 프로젝트를 본 사실이 아니라 결과 이미지·영상만 보고 추정한 것이라는 점이며, 상세 오류 처리는 구현 단계에서 구체화한다.

[10 이해 확인] 팀장은 핵심 흐름을 “사용자는 로컬 라이브러리에 영상 및 캡처 자료를 넣고, 프로세스를 키면 그 자료들을 적합한 폴더에 분류하고 태깅 데이터를 저장하며, 프로세스 윈도우에서 필터를 조작하면 원하는 자료가 검색 결과로 출력된다”라고 재설명했고, 팀원 간 기대 결과 일치는 미확인이다. 확인 근거 또는 한계는 함께 확인하지 못함이다.

[11 실제 멘토 질문] 실제 멘토에게 완성된 이미지·영상만으로 추정한 제작 방식 태그를 추천 기준으로 사용하는 것이 시연 가치와 신뢰성 측면에서 적절한지, 그리고 그 추정 기능을 당일 구현 범위에서 어느 수준까지 제한해야 하는지 묻는다.

## 상태와 사람 멘토 확인

- 문제·가치 가설 상태: 사람 멘토 검토 가능 — 영상 편집자라는 목표 사용자와 특수효과 레퍼런스를 다시 찾는 구체적 상황, 현재 대안과 불편, 기대 변화, 팀장의 직접 경험과 다른 제작자에게 직접 들은 유사 경험이 문장에 있다.
- 제품·범위 상태: 사람 멘토 검토 가능 — 신규 자료 1~2개 추가 → 자동 분류·태깅 → 필터 검색 → 관련 자료와 추천 효과 확인이라는 핵심 흐름, 포함·제외 범위, `pixel glitch` 예시의 기대 결과가 서로 모순되지 않는다.
- 실제 멘토가 확인·수정할 것: 완성된 결과 이미지·영상만으로 제작 방식을 추정해 추천하는 접근의 신뢰성과 당일 구현 범위
- 고객 가치 검증 상태: 미검증
- 제품 작동 검증 상태: 사전 문장 작성 단계에서는 미검증
