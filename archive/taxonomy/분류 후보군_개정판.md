# 분류 후보군 — 서비스용 태그 사전 (개정판)

## 목적

이 문서는 영상 효과 태깅 서비스에서 사용하는 표준 태그 사전의 seed data다. 원본의 8개 대분류와 기존 용어를 보존하되, 각 용어를 검색·분석·저장에 사용할 수 있는 정규화된 태그로 정의한다.

## 스키마

각 태그는 아래 최소 메타데이터를 가진다.

- `id`: 서비스 내부에서 변하지 않는 canonical ID. `namespace.slug` 형식이며, 표시 이름을 바꾸더라도 유지한다.
- `aliases`: 검색어 정규화에 쓰는 동의어·약어 목록. 검증된 별칭이 아직 없으면 빈 배열(`[]`)로 남기며, 운영 과정에서 추가한다.
- `parent`: 같은 namespace 안에서의 상위 분류 ID. 현재 원본 구조를 보존하기 위해 각 항목은 해당 대분류의 `.root`에 연결한다. 향후 세부 계층을 만들 때 하위 태그의 parent만 변경한다.
- `observable`: 영상 결과만 보고 직접 관찰 가능한지 여부. `false`는 제작 과정 또는 생성 방식을 확정할 수 없으므로 AI 추정 또는 사용자 입력으로 다룬다.

## 명명 규칙

- namespace는 8개 대분류와 일치한다: `visual_style`, `generation_method`, `production_technique`, `transformation`, `motion_style`, `texture`, `geometry_pattern`, `compositing`.
- ID의 slug는 영문 소문자와 underscore만 쓴다. 예: `RGB Split` → `rgb_split`.
- 같은 표시 이름이 여러 분류에 존재해도 삭제하거나 병합하지 않는다. namespace를 포함한 ID로 구분한다. 예: `visual_style.rgb_split`과 `transformation.rgb_split`.
- `observable: false` 태그는 화면상 단서가 있더라도 사용된 정확한 기법·알고리즘을 확정하는 뜻으로 사용하지 않는다.
